# راه‌اندازی روی سرور — قدم به قدم

سروری که لازم داری: **Ubuntu 24.04**، حداقل **۴ گیگ رم**، ۱ هسته کافی است.

کل کار سه مرحله است و حدود بیست دقیقه طول می‌کشد.

---

## مرحله ۱ — رکورد DNS

قبل از هر چیز، در پنل دامنه (ایران‌سرور) دو رکورد بساز:

| نوع | نام | مقدار | TTL |
| --- | --- | --- | --- |
| A | `@` | ‏IP سرور | ۳۰۰ |
| A | `www` | ‏IP سرور | ۳۰۰ |

نیم ساعت صبر کن. برای اینکه ببینی جا افتاده یا نه، روی لپ‌تاپ خودت بزن:

```bash
nslookup shahrzadlaser.ir
```

اگر IP سرورت را نشان داد، آماده است. اگر نه، کمی بیشتر صبر کن — مرحله‌ی
بعد بدون این هم کار می‌کند، فقط SSL را باید بعداً دستی بگیری.

---

## مرحله ۲ — اتصال به سرور

ایران‌سرور به تو یک IP و رمز root داده. از ترمینال لپ‌تاپت:

```bash
ssh -p 3031 root@IP-سرور
```

> **پورت را جدی بگیر.** ایران‌سرور SSH را روی **۳۰۳۱** می‌گذارد، نه ۲۲.
> اگر `-p 3031` را ننویسی، `Connection timed out` می‌گیری و فکر می‌کنی
> سرور خراب است. پورت درست در ایمیل فعال‌سازی سرویس نوشته شده — اگر
> ارائه‌دهنده‌ات فرق دارد، همان عدد را بگذار.

اولین بار می‌پرسد مطمئنی؟ بنویس `yes` و رمز را وارد کن.
(موقع تایپ رمز هیچ چیزی روی صفحه نمی‌آید — طبیعی است، تایپ کن و اینتر بزن.)

**VNC لازم نیست.** VNC فقط کنسول اضطراری است؛ همه‌ی کار با SSH انجام می‌شود.

---

## مرحله ۳ — گرفتن کد

مخزن **خصوصی** است، پس گیت‌هاب توکن می‌خواهد. رمز حساب گیت‌هاب کار نمی‌کند —
گیت‌هاب سال‌هاست رمز را برای git قبول نمی‌کند.

**ساخت توکن** (یک بار، روی مرورگر خودت):

1. `github.com` → عکس پروفایل → **Settings**
2. پایین‌ترین گزینه: **Developer settings**
3. **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**
4. یک نام بگذار (مثلاً `سرور کلینیک`)، مدت اعتبار را انتخاب کن
5. تیک **`repo`** را بزن (فقط همین یکی)
6. **Generate token** → توکن را کپی کن (فقط همان یک بار نشان داده می‌شود)

**روی سرور:**

```bash
git clone --branch claude/beauty-clinic-website-7ej1e7 \
  https://github.com/amirhosein13/sharzadclinic.git /tmp/sharzad-setup
```

- `Username` → نام کاربری گیت‌هابت
- `Password` → **توکن** را بچسبان (نه رمز حساب)

## مرحله ۴ — اجرای اسکریپت

```bash
bash /tmp/sharzad-setup/deploy/setup-server.sh
```

اسکریپت کد را از همان نسخه‌ای که گرفتی کپی می‌کند، پس **دوباره توکن نمی‌خواهد**.

اسکریپت سه سؤال می‌پرسد:

1. **دامنه** — مثلاً `shahrzadlaser.ir` (بدون `www` و بدون `https://`)
2. **ایمیل برای SSL** — هشدار انقضای گواهی به این می‌آید
3. **ایمیل ورود مدیر** — پیش‌فرض `admin@دامنه‌ات`

بعد بنشین و نگاه کن. حدود ۱۵ دقیقه طول می‌کشد (بیشترش نصب پکیج‌ها و
ساخت برنامه است).

**اسکریپت چند بار هم اجرا شود مشکلی ندارد** — هر کاری که قبلاً انجام شده را
رد می‌کند و هیچ‌وقت دیتابیس یا فایل `.env` موجود را پاک نمی‌کند.

## چه چیزی نصب می‌شود

| | |
| --- | --- |
| Node.js 22 | مخزن اوبونتو ۱۸ دارد که قدیمی است |
| PostgreSQL 16 | دیتابیس، با رمز تصادفی |
| Nginx | SSL، فشرده‌سازی، محدودکردن تلاش ورود |
| certbot | گواهی SSL رایگان، تمدید خودکار |
| ufw + fail2ban | فایروال؛ فقط ۲۲، ۸۰ و ۴۴۳ باز |
| systemd | برنامه بعد از ری‌استارت سرور خودکار بالا می‌آید |
| cron | یادآوری، گزارش شبانه، پیامک گروهی، پشتیبان‌گیری |

## بعد از تمام شدن

سایت روی `https://دامنه‌ات` بالاست و پنل روی `/admin`.

اسکریپت در پایان یک **رمز تصادفی** نشان می‌دهد. همان لحظه جایی امن
ذخیره‌اش کن — دوباره نشان داده نمی‌شود.

> رمز پیش‌فرضِ داخل مخزن (`Admin@12345`) عمداً روی سرور استفاده نمی‌شود،
> چون مخزن عمومی است و هر کسی می‌تواند بخواندش.

اگر گمش کردی:
```bash
grep ADMIN_PASSWORD /var/www/sharzad/.env
```
یا رمز تازه بساز:
```bash
cd /var/www/sharzad && sudo -u sharzad npm run reset-password -- --email ایمیلت
```

### پنج کار اول در پنل

1. **تنظیمات** → نام، تلفن، آدرس و ساعت کاری کلینیک
2. **تنظیمات** → نام کاربری و رمز ملی‌پیامک (بدون این، پیامک و ورود مشتری کار نمی‌کند)
3. **کاربران** → برای منشی حساب بساز، و **شماره موبایل** هر حساب را پر کن
   (بدون شماره، بازیابی رمز هیچ راهی ندارد)
4. **سلامت سیستم** → یک بار باز کن و هر چه قرمز بود درست کن
5. **پشتیبان‌گیری** → یک نسخه بگیر و روی گوشی‌ات دانلود کن

## دستورهایی که لازمت می‌شود

```bash
# وضعیت برنامه
systemctl status sharzad

# لاگ زنده — وقتی چیزی کار نمی‌کند اول اینجا را ببین
journalctl -u sharzad -f

# ری‌استارت
systemctl restart sharzad

# لاگ کارهای خودکار (پشتیبان، یادآوری، ...)
tail -f /var/log/sharzad-cron.log

# جای خالی دیسک
df -h /

# رمز دیتابیس (اگر لازم شد)
cat /root/.sharzad-db-pass
```

## اگر به مشکل خوردی

**`Connection timed out` موقع SSH**
احتمالاً پورت را اشتباه زده‌ای. ایران‌سرور روی ۳۰۳۱ است:
```bash
ssh -p 3031 root@IP-سرور
```
اگر باز هم نشد، با اینترنت موبایل امتحان کن — بعضی اینترنت‌های خانگی در
ایران پورت‌های غیرمعمول را می‌بندند.

**بعد از اجرای اسکریپت دیگر نمی‌توانم SSH بزنم**
نباید پیش بیاید: اسکریپت قبل از روشن‌کردن فایروال، پورت واقعی SSH را
پیدا می‌کند و بازش می‌گذارد. اگر با این حال گیر کردی، از کنسول VNC در
پنل ایران‌سرور وارد شو و بزن:
```bash
ufw allow 3031/tcp && ufw reload
```

**سایت باز نمی‌شود**
```bash
systemctl status sharzad     # برنامه بالاست؟
systemctl status nginx       # nginx بالاست؟
journalctl -u sharzad -n 50  # آخرین خطاها
```

**«گواهی SSL معتبر نیست»**
یعنی certbot موقع نصب نتوانسته گواهی بگیرد، چون DNS هنوز جا نیفتاده بود.
حالا که جا افتاده:
```bash
certbot --nginx -d دامنه‌ات -d www.دامنه‌ات --redirect
```

**برنامه بالا نمی‌آید و لاگ می‌گوید حافظه کم است**
روی سرور ۴ گیگ نباید پیش بیاید، ولی اگر آمد، فضای swap اضافه کن:
```bash
fallocate -l 2G /swapfile && chmod 600 /swapfile
mkswap /swapfile && swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
```

**`npm ci` گیر می‌کند یا خطای شبکه می‌دهد**
رجیستری npm از داخل ایران فیلتر است. اسکریپت خودش این را می‌گیرد و آینه
تنظیم می‌کند، ولی اگر باز هم مشکل داشتی:
```bash
npm config set registry https://registry.npmmirror.com --location=global
```
